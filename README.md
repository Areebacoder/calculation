# 🧮 C++ Calculator

A simple **Calculator Program in C++** developed using **Object-Oriented Programming (OOP)** concepts.

## 📌 About the Project

This project creates a calculator using a C++ class named `calculator`. The program takes two numbers from the user and performs four basic mathematical operations:

* Addition
* Subtraction
* Multiplication
* Division

The program uses separate member functions for each operation and a `display()` function to show the final results.

## ✨ Features

* Takes two numbers as input from the user
* Performs addition
* Performs subtraction
* Performs multiplication
* Performs division
* Uses a C++ class and objects
* Displays all results in a formatted output

## 🛠️ Technologies Used

* **Language:** C++
* **Concept:** Object-Oriented Programming (OOP)
* **Header File:** `<iostream>`

## 📚 OOP Concepts Used

### 1. Class

The project uses a class named `calculator` to store data and functions together.

### 2. Object

An object `c` of the `calculator` class is created in the `main()` function.

### 3. Member Variables

The class contains two floating-point variables:

```cpp
float num1;
float num2;
```

### 4. Member Functions

The calculator class contains functions for:

```cpp
setdata()
addition()
subt()
mult()
divi()
display()
```

These functions handle input, calculations, and output.

## ▶️ How to Run

1. Download or clone this repository.
2. Open `calculation.cpp` in a C++ IDE such as **Dev-C++**, **Code::Blocks**, or **Visual Studio**.
3. Compile the program.
4. Run the program.
5. Enter two numbers when prompted.
6. The calculator will display the results.
